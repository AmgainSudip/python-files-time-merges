# Working with Files, Time, and Merges

This repository contains a Python notebook exploring practical techniques for working with files, handling timestamps, validating data, and merging datasets using pandas.

The notebook uses a bike-share dataset containing ride, station, and weather information.

## Topics Covered

- Reading and managing CSV files
- Data validation using Python `assert` statements
- Loading files using user prompts
- Connecting Google Drive
- Reading data from GitHub
- Merging DataFrames using common keys
- Working with UTC and local time zones
- Merging datasets using timestamps

## Additional Features

- Automatic data quality report
- Station performance analysis
- Station activity visualization
- Hourly bike-ride analysis
- Exporting analysis results to CSV
- Downloading results as a ZIP file

## Requirements

- Python 3
- pandas
- NumPy
- Matplotlib

## How to Run

1. Open the notebook in Google Colab or Jupyter Notebook.
2. Run the cells from top to bottom.
3. Explore the examples and additional analysis features.

## Purpose

The purpose of this notebook is to practice Python data-handling techniques and apply them to a practical bike-share data analysis project.
